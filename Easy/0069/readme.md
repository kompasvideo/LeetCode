# 69. Sqrt(x)
Для неотрицательного целого числа x верните квадратный корень из x с округлением до ближайшего целого. Возвращаемое целое число также должно быть неотрицательным.

Вы не должны использовать ни одну из встроенных функций или операторов возведения в степень.

Например, не используйте pow(x, 0.5) в C++ или x ** 0.5 в Python.

Пример 1:
>Входные данные: x = 4   
Выходные данные: 2
Пояснение: Квадратный корень из 4 равен 2, поэтому мы возвращаем 2.    

Пример 2:   
> Входные данные: x = 8   
Выходные данные: 2   
 
Ограничения:
* 0 <= x <= 2³¹ - 1
