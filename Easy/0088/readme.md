# 88. Объединить отсортированный массив
Вам даны два массива целых чисел nums1 и nums2, отсортированные в неубывающем порядке, и два целых числа m и n, представляющих количество элементов в nums1 и nums2 соответственно.

Объединить nums1 и nums2 в единый массив, отсортированный в неубывающем порядке.

Окончательный отсортированный массив не должен быть возвращен функцией, но вместо этого должен быть сохранен внутри массива nums1. Для этого nums1 имеет длину m + n, где первые m элементов обозначают элементы, которые нужно объединить, а последние n элементов равны 0 и должны быть проигнорированы. nums2 имеет длину n.

Пример 1:   

>Входные данные: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3   
Выходные данные: [1,2,2,3,5,6]   
Объяснение: Массивы, которые мы объединяем, — это [1,2,3] и [2,5,6].   
Результатом объединения будет [1,2,2,3,5,6], где подчеркнутые элементы взяты из nums1.

Пример 2:    

>Входные данные: nums1 = [1], m = 1, nums2 = [], n = 0   
Выходные данные: [1] 
Пояснение: Объединяемые массивы: [1] и [].   
Результат объединения: [1]. 

Пример 3:

>Входные данные: nums1 = [0], m = 0, nums2 = [1], n = 1   
Выходные данные: [1]   
Объяснение: Массивы, которые мы объединяем, — это [] и [1].   
Результатом объединения является [1].   
Обратите внимание, что, поскольку m = 0, в nums1 нет элементов. Цифра 0 нужна только для того, чтобы результат объединения поместился в nums1.   

Ограничения:

* nums1.length == m + n
* nums2.length == n
* 0 <= m, n <= 200
* 1 <= m + n <= 200
* -109 <= nums1[i], nums2[j] <= 109
