# 67. Добавьте двоичный код
Даны две двоичные строки a и b, верните их сумму в виде двоичной строки.

Пример 1:
>Входные данные: a = "11", b = "1"   
Выходные данные: "100"   

Пример 2:   
> Входные данные: a = "1010", b = "1011"   
Выходные данные: "10101"   
 
Ограничения:
* 1 <= a.length, b.length <= 10⁴
* a и b состоят только из '0' или '1' символов.
* Каждая строка не содержит ведущих нулей, кроме самого нуля.
