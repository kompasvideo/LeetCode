# 83. Удалить дубликаты из отсортированного списка
Дан head отсортированный связный список. Удалите все дубликаты так, чтобы каждый элемент встречался только один раз. Верните связный список в отсортированном виде.


Пример 1:   

![List1](list1.jpg "List1")
>Входные данные: head = [1,1,2]   
Выходные данные: [1,2]

Пример 2:    

![List2](list2.jpg "List2")
>Входные данные: head = [1,1,2,3,3]   
>Выходные данные: [1,2,3]
 

Ограничения:

* Количество узлов в списке находится в диапазоне [0, 300].
* -100 <= Node.val <= 100
* Список гарантированно отсортирован в порядке возрастания.
